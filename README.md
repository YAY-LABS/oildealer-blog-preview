# OilDealer Blog Preview

Temporary static blog preview for OilDealer marketing/content review before the real blog/CMS is ready.

## Current page

- `index.html`: 앱 디자인 시스템을 반영한 오일딜러 블로그 프리뷰
- Topic: `국제유가 내려도 발주 단가가 안 내려가는 이유`

## Local run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

Manual from this directory:

```bash
npx vercel
```

Production deploy:

```bash
npx vercel --prod
```

## Notes

- This is a preview repo, not the final `oildealer.co.kr/blog` implementation.
- External publishing / Vercel deployment should be done only after Mindy approval.
- Source assets are copied from publicly available Google Play app listing screenshots/icons for internal preview alignment.
